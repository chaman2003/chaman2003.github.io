## 🎯 About

A sleek, performance-focused portfolio showcasing my work as a developer. Built with a **hybrid architecture** — static HTML content shell enhanced with React for interactivity and vanilla JS for buttery-smooth animations.

## ⚡ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Framework** | React 19, Vite 6 |
| **Styling** | Tailwind CSS 4, Custom CSS |
| **Animations** | GSAP, Framer Motion, Lenis (smooth scroll) |
| **3D / Visuals** | Three.js, Custom particle effects |
| **State** | React Context API |
| **Tooling** | ESLint, Prettier, PostCSS |

## ✨ Features

- 🌗 **Animated Theme Toggle** — Smooth dark/light mode transitions
- 🖱️ **Custom Smooth Cursor** — GPU-accelerated cursor with trail effects
- 🎬 **GSAP Animations** — Scroll-triggered reveals, text animations, parallax
- 🌊 **Smooth Scrolling** — Lenis-powered buttery smooth page navigation
- 📱 **Fully Responsive** — Looks great on every screen size
- ⚡ **Fast AF** — Static HTML shell means instant first paint
- 🐙 **GitHub Integration** — Live repo stats pulled via GitHub API

## 🏗️ Architecture

```
src/
├── app/              # App entry, providers, layout
├── components/       # Reusable UI (ThemeToggler, SmoothCursor)
├── features/
│   └── portfolio/    # Core portfolio modules
│       ├── gsap.js         # Scroll animations
│       ├── three.js        # 3D background effects
│       ├── particles.js    # Particle system
│       ├── github.js       # GitHub API integration
│       ├── smoothScroll.js # Lenis setup
│       └── theme.js        # Theme management
├── config/           # App configuration
├── hooks/            # Custom React hooks
├── lib/              # Shared utilities
└── styles/           # Global styles
```

> **Hybrid Model:** The page loads as static HTML for instant rendering, then React hydrates interactive components while vanilla JS modules handle animations independently.

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/chaman2003/chaman-portfolio.git
cd chaman-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
